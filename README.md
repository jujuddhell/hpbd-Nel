# Изумрудная стена поздравлений

## Запуск
1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Фоновое изображение уже подключено: `assets/stena_s_foto.jpg`.

## Как заменить фоновую картинку
Замените файл `assets/stena_s_foto.jpg` на своё изображение с тем же именем. Важно: это изображение используется целиком как фон стены, включая фотографию в оконной нише.

## Как изменить поздравления
Откройте `script.js`, найдите массив `greetings`.
Для каждого гостя укажите:
- `name` — имя;
- `signature` — подпись в карточке;
- `text` — поздравление;
- `x`, `y` — координаты надписи в процентах от ширины и высоты стены;
- `tilt` — наклон надписи в градусах.

Добавляйте и удаляйте записи в этом массиве. Сейчас включены 12 демонстрационных поздравлений.

## Как поменять оформление
Откройте `style.css`. Основные стили кирпичной стены больше не рисуют кладку: они накладывают интерактивные подписи поверх пользовательского изображения. Можно менять шрифт, цвет, тень и эффекты наведения в блоке `.guest-name`.

## Важно про размещение
Координаты подписей в `script.js` подобраны так, чтобы обходить центральное круглое окно на исходном изображении. Если заменить фон на изображение с другим расположением окна, поправьте `x` и `y`.
